# MagicBooks 📚

Библиотека полных текстов классики «новой мысли», закона притяжения и психологии успеха —
подготовлена как база знаний для AI-агентов (RAG, ассистенты, Telegram-боты).

Источник списка: подборка из 20 книг (обсуждение в Perplexity). В репозиторий загружены
**только тексты в общественном достоянии** — с Project Gutenberg и Global Grey Ebooks,
в оригинале на английском.

## ⚠️ Заметки

- **Холмс, «Сила разума»** — точное соответствие русскому изданию не подтверждено, поэтому
  загружены обе книги-кандидата (7a, 7b).
- **Хилл и Годдард** — статус общественного достояния определён по данным Global Grey
  (американские издания 1928–1963 гг., чьё авторское право не было продлено). В других
  странах статус может отличаться; русские переводы — отдельные объекты авторского права.
- Все тексты — **на английском**. Для русскоязычного бота агенту стоит переводить цитаты
  на лету или добавить купленные русские издания.
